*最新版 **V3 CLite** 實機選單展示（半透明深色浮動卡片、Sony Alpha 橘金狀態高亮與繁體中文介面）。*

以 **MENU＋放大鏡** 召喚自製觸控選單，在相機上管理 LUT 開關和 Film 選項的研究專案。

**本專案仍在持續開發與更新，目前處於實驗階段。** 選單操作、LUT 管理與拍攝後處理會隨實機驗證逐步完善；已驗證的功能、已知限制及待完成項目會同步更新在下方的「實際進度」與 [功能狀態](docs/功能狀態.md) 中。

## 這個版本包含甚麼？

- **A6400 V3 CLite 自製選單**：採用半透明深色浮動卡片、頂部 Sony Alpha 橘條與繁體中文介面，含觸控命中判斷、無限重複召喚與右下角獨立 `關閉`／`返回` 按鈕。
- **LUT 與膠片設定保留**：支援 `LUT 濾鏡: 開啟／關閉`、5 款 `膠片風格` 選擇（`Portra 400`、`CineStill 800T`、`Fuji Provia`、`Kodak Gold`、`Tri-X 400`）與暖琥珀／橘金狀態高亮；關閉選單不影響已開啟的 LUT。
- **設定讀取與套件安全檢查**：包含 1120-byte snapshot ABI 驗證、背景派工條件、只讀設定 CLI，以及套件建置期對 `a6400-film-ram-job.sh` 內部雜湊的強制一致性防呆。
- **照片掃描與原生檔案協調**：支援僅掃描最新 DCF 目錄、`mmc0` 中斷觸發（排除 `emmc0`）、動態解析 SD 卡 `B:`／`A:` 磁碟代號，以及寫回、強制 `flush` 與讀回解碼驗證。
- **原生 UI 接駁與建置工具**：研究用載入保護（含瞬時執行緒變動重試）、`--gc-sections` 體積精簡建置與套件組裝腳本。
- **電腦端自動化驗證**：可在一般電腦執行的合成資料與控制測試；不需要連接相機或 Sony 韌體。

**這是研究用原始碼公開版，並非可直接複製到 SD 卡的完整安裝包。** 原生 UI 接駁使用特定實機版本的地址與佈局，不能假設適用於其他機身或韌體。

## 在電腦上執行測試與部署入口

需要 Python 3.10 以上、C 編譯器，以及一般 POSIX 開發環境。測試只在暫存目錄操作合成資料，**不會連接相機、修改記憶體或掛載 SD 卡**。

```sh
git clone https://github.com/PCIEARIA/A6400-Extra-Menu.git
cd A6400-Extra-Menu
python3 -m unittest discover -p 'test_*.py' -v
python3 tools/check_public_tree.py
```

若要從本倉庫進行相機端交叉編譯、組裝套件並透過 `Sony-PMCA-RE` 部署到另一台 A6400，請直接閱讀 **[部署與操作規範](docs/部署與操作規範.md)**（並搭配 [編譯與目錄說明](docs/編譯與目錄.md)）。

## 研究上的界線

相機原生 UI 與媒體管理路徑仍在調試。過往版本曾出現黑屏、卡住或輸入失靈，斷電後恢復；目前沒有證據足以保證所有狀態都安全。請先閱讀程式與版本檢查，不要把測試通過理解成可以直接安裝。

拍攝時不應從另一個 Linux 掛載點直接讀寫相機正在管理的 SD 卡。原片與輸出必須分開；完成狀態不確定時，協調程式保留現場並停止後續派工。
