# 功能狀態與限制

> ⚠️ **V3 Beta 實驗分支聲明（`beta-v3-bling-shutter`，尚未經過核實認證）**：
> 本分支新增開機前原生快門音 `MS_BIND` 研究（[`camera/bling_bind.c`](../camera/bling_bind.c)）與 `A6400_BETA_BLING_SHUTTER` / `A6400_BETA_PREBOOT_NATIVE_SHUTTER` 選單預覽，**目前僅完成編譯與電腦端單元測試，尚未在實機完成冷開機實拍與連拍核實認證，請小心使用。** 若需穩定版，請使用 `main` 分支（`v3-clite-stable-20261117`）。

更新日期：2026 年 11 月 17 日。這份狀態描述研究時的實測範圍，不是通用相容性保證。

## 已有實機結果

- 在測試機上，MENU＋放大鏡可召喚自製原生圖層選單（最新 **`A6400 V3 CLite`** 採用半透明浮動深色卡片、頂部 Sony Alpha 橘條與繁體中文標籤，已於實機確認原生字型 `0x02076000` 可正常顯示中文）；於關閉、20 秒自動隱藏與原生鍵退出後可重複召喚。
- 觸控 LUT 開關、Film 選擇與右下角獨立 `關閉`／`返回` 按鈕已有成功測試，開啟或選中項目會以暖琥珀底色與橘金側條高亮；關閉後設定可保留，原生按鍵與觸控維持正常。
- 已解決真冷開機（不接 USB）時 `libInfraFsys` 因內部 NAND `/dev/nflasha23` 先掛載於 `A:`、SD 卡 `/dev/mmca` 掛載於 `B:` 造成的讀寫失敗問題，並在未掛載時改為安全中止而非退回 `A:`。
- 已於 `v2-lite-fix7` 與 `V3 CLite` 完成不插 USB 冷開機現拍 JPEG 實測（約 21–22 秒／張，含原圖只讀保護、濾鏡處理、寫入 SD、`flush` 與讀回解碼雜湊驗證）。
- 已修復 [`film_native_command.c`](../camera/film_native_command.c) 的雙重指令回顯重錨定問題：當指令進入佇列後、原生 Shell 真正執行前仍排出先前排隊的背景 `ERROR` 訊息時，會以第二次實際執行回顯重新對齊回應起點（不放寬執行期錯誤檢查），避免剛拍完照片後的背景日誌誤觸發 `native_error`。
- 已新增只掃描最新 DCF 目錄、`mmc0` 中斷（排除 `emmc0`）觸發掃描、執行緒凍結重試、`--gc-sections` 精簡空間與套件建置時驗證 `a6400-film-ram-job.sh` 內部雜湊一致等改善。

## 尚待擴充驗證的部分

- `OFF` 自動略過與切換為 `Tri-X` 等更多預設的專屬多輪冷開機驗收尚待獨立補測。

## 目前限制

- 初次載入研究 UI 曾需要在正常拍攝畫面輕觸並放開螢幕。
- UI 有單次顯示時限；設定目前在 RAM，不能假設斷電後保留。
- UI、讀取器與 guard 必須配合確切的編譯結果、地址及版本檢查。
- 背景處理是拍攝後 JPEG 另存，不是即時取景濾鏡、RAW 改寫或影片 LUT。
- metadata 穩定等待只是候選判斷，不等於 Sony 寫檔完成通知；讀回／解碼驗證仍不可省略。
- 目前輸出使用獨立的 `/A6400/TEST/` 目錄（依目前 `/dev/mmca` 掛載代號為 `A:` 或 `B:`），沒有宣稱已註冊到相機播放資料庫。
- 佇列有 128 個生命週期項目上限（開啟只掃描最新 DCF 目錄可壓縮舊目錄基線）；仍沒有完成可無限持續拍攝的完整監督與回收策略。
- 公開版不含上游濾鏡引擎或現成安裝包，詳見第三方來源說明。

## 故障記錄與測試界線

較早的 UI 試驗曾黑屏、卡住或令部分輸入失靈；取出電池後恢復。後續特定版本通過的短測，不能推廣成所有相機狀態都不會發生問題。

電腦端測試使用合成資料和替代 monitor，只能驗證程式邏輯、解析與失敗處理；不代表已實際呼叫 Sony 硬體或成功寫入 SD 卡。
